# IRCTC Train Information System

A scaled-down version of the IRCTC railway portal that stores and displays real Indian Railways train data for 10 major cities. Built with **MySQL**, **Python** and **Flask**.

This project covers train information only (stations, routes, stops, schedules, seat classes and fares). It does **not** include a ticket booking algorithm.

## Features

- Normalized relational schema with 6 tables and foreign key relationships
- Data pipeline that cleans and imports real-world JSON data into MySQL
- Reusable Python query layer for searching trains and viewing schedules
- Flask web interface for searching trains between two stations (in progress)

## Database schema

```
stations ──┬──< routes >── trains
           │       │
           │       ├──< route_stops
           │       └──< schedules ──< seat_classes
           └─ (nullable FK) ──< route_stops
```

| Table | Purpose |
|---|---|
| `stations` | The 10 stations with name, city, state and station code |
| `trains` | Train number, name and type (Express, Rajdhani, Duronto, etc.) |
| `routes` | Links a train to its origin and destination station |
| `route_stops` | Every stop of a train in order, with arrival and departure times |
| `schedules` | A route running on a specific date |
| `seat_classes` | Seat classes (Sleeper, 3AC, 2AC, 1AC, Chair Car) per schedule with seats and fare |

`route_stops.station_id` is nullable because intermediate stops can be stations outside the 10 selected cities. The raw `station_code` and `station_name` are stored for those.

## Data summary

After import, the database contains:

| Table | Rows |
|---|---|
| stations | 10 |
| trains | 105 |
| routes | 105 |
| route_stops | 18,663 |
| schedules | 525 (5 generated dates per train) |

Schedule dates and seat availability are generated by the import script. Seat classes are derived from the class flags in the dataset, and fares and seat counts are sample values.

## Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/<your-username>/IRCTC_Project.git
   cd IRCTC_Project
   ```

2. **Install dependencies**
   ```bash
   pip install mysql-connector-python flask
   ```

3. **Create the database and tables** (in the MySQL command line)
   ```sql
   CREATE DATABASE irctc_db;
   ```
   ```bash
   mysql -u root -p irctc_db < schema.sql
   ```

4. **Download the dataset** from the Kaggle link above and place `stations.json`, `trains.json` and `schedules.json` in the project folder. These files are not included in the repo because of their size.

5. **Add your MySQL password** in `db_connect.py`, `import_data.py` and `queries.py`.

6. **Import the data**
   ```bash
   python import_data.py
   ```

7. **Run the Flask app**
   ```bash
   python app.py
   ```

## Example queries

Find trains between two stations:

```sql
SELECT t.train_number, t.train_name, t.train_type,
       s1.city AS from_city, s2.city AS to_city,
       sc.journey_date, sc.departure_time, sc.arrival_time
FROM schedules sc
JOIN routes   r  ON r.route_id    = sc.route_id
JOIN trains   t  ON t.train_id    = r.train_id
JOIN stations s1 ON s1.station_id = r.origin_id
JOIN stations s2 ON s2.station_id = r.destination_id
WHERE s1.station_code = 'MAS'
  AND s2.station_code = 'HWH'
ORDER BY sc.journey_date, sc.departure_time;
```

List which city pairs have direct trains:

```sql
SELECT s1.city AS from_city, s2.city AS to_city, COUNT(*) AS number_of_trains
FROM routes r
JOIN stations s1 ON s1.station_id = r.origin_id
JOIN stations s2 ON s2.station_id = r.destination_id
GROUP BY s1.city, s2.city
ORDER BY number_of_trains DESC;
```

## Data cleaning notes

Real-world data needed some handling during import:

- Null values in `state` replaced with `"Unknown"`
- Null `day` values in the schedules file defaulted to day 1 when sorting stops
- Arrival and departure values stored as the string `"None"` converted to SQL `NULL`
